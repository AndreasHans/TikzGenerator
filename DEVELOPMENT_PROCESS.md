# Development Process

This tool was developed entirely through AI-assisted generation — no code was written by hand.

## Process

1. **Specification** — The developer wrote a brief description of the desired functionality (generating TikZ diagrams for state machines and Mealy machines).
2. **Planning** — AI produced a detailed implementation plan. The developer reviewed the plan and provided corrections, which AI incorporated into revised plans.
3. **Implementation** — AI wrote all code based on the approved plan.
4. **Iteration** — The developer reviewed the generated TikZ output, identified issues or missing features, and gave feedback. AI then revised the code accordingly. This feedback loop repeated until the output was correct.
